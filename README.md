## Overview

This project is a Power BI implementation of my E-Commerce Sales Performance & Customer Insights Dashboard using the same e-commerce sales dataset from 2024–2025.

The focus of this version is on building an interactive Business Intelligence dashboard through Power Query, DAX measures, and data transformation. The raw dataset was cleaned, transformed, and modeled to create meaningful KPIs and visualizations that provide insights into sales performance, profitability, customer demographics, and monthly sales trends.

This project demonstrates my ability to transform raw business data into an interactive dashboard that supports data-driven decision-making.

## Features

Data Cleaning and Transformation using Power Query.

DAX Measures for business KPI calculations.

Interactive KPI Cards and Visualizations.

Customer Demographic Analysis.

Sales and Profitability Analysis.

Monthly Sales Trend Analysis.

Product Performance Analysis.

Customer Age Group Analysis.

Interactive Slicers and Filters.

Dashboard Reporting in Power BI.

## Data Cleaning & Transformation

The dataset was prepared inside Power Query before creating the dashboard.

## Data Cleaning

Removed duplicate records to improve data accuracy.

Cleaned and transformed data fields for consistent reporting.

Prepared the dataset for analysis and visualization in Power BI.

## Data Transformation

Created a custom Age Group column to categorize customers into:

Young Adults — Age below 30.

Middle Age — Age 30 to 45.

Older Adults — Age above 45.

Extracted the Month from the Order Date column to support monthly sales trend analysis.

These transformations improve customer segmentation and make time-based analysis easier to interpret.

## DAX Measures Created

The dashboard includes custom DAX measures to calculate key business metrics.

**Measures**

Total Sales	Calculates the total revenue generated from all completed sales transactions.

Total Profit	Calculates the overall profit earned from all sales.

Total Cost	Calculates the total product cost across all orders.

Total Orders	Counts the total number of customer orders.

Total Discounts	Calculates the total discount amount applied across all transactions.

**Purpose** 

These measures are displayed as KPI cards and used across multiple visualizations throughout the dashboard.
